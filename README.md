# AWS Cloud Practitioner Simulados

Este projeto é apenas um site simples para realizar simulados da certificação AWS Cloud Practitioner.

A aplicação foi construída com React Router e utiliza prerender nas páginas dos exames para melhorar a navegação e a distribuição do conteúdo.

As questões foram obtidas do repositório [AWS-Certified-Cloud-Practitioner-Notes](https://github.com/kananinirav/AWS-Certified-Cloud-Practitioner-Notes).
